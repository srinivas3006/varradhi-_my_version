UI fixes applied

  • Header now has a back button + a one-line subtitle — "Post News" alone felt orphaned right under the status bar.
  • Unselected post-type card now has a visible border (was invisible in your screenshot, looked disabled/unclickable).
  • Upload box shows a real filled state: thumbnail preview, remove (✕), and a photo-count badge — right now it only shows the empty placeholder state.

  • Category row: kept your red pill style, just made unselected chips consistent (equal padding/border) — a couple looked wider than others in the original.

One-time OTP gate — how it flows

  • 1Signup collects only email/username + password. No OTP. Fast onboarding, matches your ask.
  • 2User fills the Post form freely and taps Submit for Review.
  • 3App checks user.isPhoneVerified. If false → post payload is held in memory, an OTP bottom sheet opens asking for phone + code, without losing their draft.
  • 4On successful verify, backend flips is_phone_verified = true once, then immediately submits the held post — user never has to tap submit twice.
  • 5Every post after this shows the green "Verified reporter" badge and skips the sheet entirely.

Django (DRF) sketch

  • User model: add phone_number, is_phone_verified = BooleanField(default=False).
  • New OTP model: phone, code, purpose='post_verification', expires_at, is_used.
  • POST /auth/send-otp/ → generates 6-digit code, SMS via your provider, 60s resend cooldown.
  • POST /auth/verify-otp/ → validates code, sets is_phone_verified=True on success, returns updated user object.
  • PostCreateSerializer/view no longer needs its own OTP check — it just requires request.user.is_phone_verified == True, enforced via a small custom permission class, e.g. IsPhoneVerifiedToPost.

Flutter sketch

  • Keep the draft post in a local PostDraft object (image, category, caption) so it survives the OTP sheet.
  • onSubmitPressed(): if authState.isPhoneVerified → call postRepository.create(draft) directly.
  • Else → showModalBottomSheet(OtpVerifySheet(draft: draft)); on success inside the sheet, call the same create(draft) and pop.
  • Cache isPhoneVerified in your auth/user Bloc state so you're not re-checking the server on every keystroke — only refresh it after a successful verify or app relaunch.
